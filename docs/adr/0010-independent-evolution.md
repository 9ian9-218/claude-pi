# ADR-0010: 独立演进——解除与 Python 版的行为等价约束

- 状态：已采纳
- 日期：2026-09-23

## 背景

最初的第一约束是"所有功能及机制不变"——即与 Python 版 Claude-Code-simple 行为等价，
靠**对拍测试**验收（同一场景分别驱动两边、比对输出）。迁移期这条约束确实挡住了行为漂移，
但它的历史载体 ADR-0005（行为等价优先）已随本 ADR 一并删除（正文见 git 历史）。

但后续实践已经出现多处**有意的**偏离，且偏离是改进而非退化：

- 压缩：阈值从固定的消息数/token 阈值改为**按模型窗口百分比**；L1 Snip / L2 Micro 移除
  （CC 无对应物，且"每轮就地改写旧工具结果"会无条件破坏 provider 缓存前缀）；新增手动
  `/compact [额外指令]`（Python 版无）。
- 传输与配置：接入 pi-ai（ADR-0007）、独立全局配置目录、模型目录自动刷新——均非 Python 版形态。
- 会话：树形 JSONL 会话与 compaction entry（ADR-0004）替代线性 messages。

继续把"与 Python 版等价"当验收约束，危害具体：对拍差异无法区分"真回归"与"已批准的改进"，
每处偏离都要重新论证；更糟的是会有人为了让对拍变绿而回退已定决策（例如把 L1/L2 加回来）。

## 决策

**claude-pi 是独立项目**：不再以"与 Python 版行为等价"为验收约束，对拍测试不再是机制
变更的准入门槛。

1. **解除约束**：原"行为等价优先"条款，以及 ADR-0002 / ADR-0003 / ADR-0007 中把对拍
   当作验收手段的表述，均不再具备约束力（相关表述已从这些 ADR 中清除）。
2. **原技术选择继续有效**：裸 OpenAI 消息结构（`messages`/`tool_calls`/`function.arguments`
   字符串/`finish_reason`，不引入 Vercel AI SDK 式抽象层）、`.agent/` 持久化格式、
   worktree 分支命名 `agent/task-<id>`、`--mode json` 输出形态，继续有效——它们现在是
   本项目的独立技术决定（理由：自实现主循环/压缩/记忆都直接处理裸消息结构）；
   要改另开 ADR。
3. **改进基准**：功能取舍以**用户需求 + CC/pi 的实测语义 + 本仓自身一致性**为准；
   跨实现比对仅在迁移期资产仍在维护时作为参考信号。
4. **对拍资产删除**（2026-09-23 决定）：`tests/parity.test.ts` 与 `scripts/parity/parity-runner.ts`
   已删除——不再保留"与 Python 版对照"的工具链。跨实现比对到此为历史记录（git 历史可查）。

## 后果

- 迁移期的"1:1 可对照"承诺到此结束：此后 claude-pi 的行为以**本仓文档与测试**为准。
- 工单 18（对拍 + 全链路冒烟）重切为**全链路冒烟**：保留 mock OpenAI 冒烟与差异记录机制，
  "与 Python 版逐场景比对"的目标与其工具链一并移除。
- ADR-0005 正文已删除（git 历史可查）；ADR-0004 / ADR-0007 中与跨实现等价相关的表述已同步清理。
